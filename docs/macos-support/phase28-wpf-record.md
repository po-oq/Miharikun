# Phase 28：WPF 版の記録と、切り出し後の照合（Issue #22）

計画 7.3「28-2 の前の記録」と、品質ゲート 3・4 の確認結果。隔離環境（`MIHARIKUN_DATA_DIR`・`MIHARIKUN_CURSOR_DIR`・`MIHARIKUN_CLAUDE_DIR` を一時フォルダに。ダミーの会話ログ・ダミーの git リポジトリ。本物のデータは使わない）。
確かめ方は UI Automation（`AutomationId`・名前）。使い捨てのハーネス（リポジトリには入れていない）で、切り出し前の WPF 版（**前**）と、切り出し後の WPF 版（**後**）を同じ手順で動かした。マウスのダブルクリックだけは実際のマウス操作。
日付：2026-10-07。Windows 11。

## 2. 変わった（計画 7.3 で「変わってよい」としたもの）

| 項目 | 前 | 後 |
|---|---|---|
| カードの ✏️ で入力中に 6.5 秒待つ | 入力欄が消える（5 秒ごとの `CardsView.Refresh()` で行が作り直され、入力が確定される） | 入力欄が残り、値もフォーカスも保たれる |

「31 件以上が一度に増えたときのスクロール」は、前も後も同じだった（今も入れ物ごとの差し替えで、同じ位置にとどまらない）。「行の『コピーしました』の消え方」は、前後で見た範囲では同じ（別の行を連続でコピーしたときの早い戻りは、ViewModel のテストで確かめた）。
