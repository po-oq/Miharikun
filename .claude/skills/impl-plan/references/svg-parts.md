# 図の部品（コピーして座標・文言を調整する）

計画の HTML の図は 4 種（全体像・前／後・状態遷移・分かれ道）。土台は `assets/plan-template.html` にあるので、**まずテンプレートの SVG をそのまま使い、足りないときにここの部品で足す**。
配色は `peraichi` スキル（設計イメージ・レビューの HTML）と同じにしてある。同じ機能の設計・計画・レビューで、色の意味がそろう。

## 寸法の決まり
- `viewBox="0 0 960 H"`・`width="960"`・`font-size="13"`・`font-family="sans-serif"` に統一。高さ H は一番下の要素 ＋ 20。
- 文字幅の目安：日本語 1 文字 ≒ font-size（13 なら 13px、12 なら 12px、11 なら 11px）。英数字・記号は約半分。
- **箱の幅 ≥ 最長の行の文字数 × 文字幅 ＋ 20**。足りなければ、①文言を短くする（図は要点だけ。詳しくは表と本文）②font-size を 1 つ下げる ③箱を広げる、の順で直す。
- 行の位置：箱の上端 y に対して、見出し（太字）は y+22、説明は +20 ずつ、最下行の補足（`fill="#555"`）は箱の下端 −18。
- 箱どうしの間は 30px 以上（矢印の分）。矢印にラベルを付けるなら 60px 以上。
- 矢印のラベルは、**次の箱の左端より手前で終わる**か確かめる（線の上に置くラベルは、はみ出しの検査にかからない）。

## 配色の約束（意味で色を決める。peraichi と共通）
| 用途 | fill | stroke |
|---|---|---|
| 外部データ・入力 | `#ffe9c8` | `#a70` |
| 既存の処理・ロジック | `#dff` | `#08a` |
| 新規・変更（新しい interface を含む） | `#dfd` | `#383` |
| 中核・共有部品（共通化で切り出すもの） | `#fef` | `#a3a` |
| 利用側（画面・API・CLI など） | `#efe` | `#383` |
| 環境・外部の仕組み・補助（ファイル・OS・仕上げ） | `#eee` | `#888` |
| 問題の箇所・失敗の分岐 | `#fde` | `#b33` |
| 強調・選択中・特別な状態（編集中など） | `#e8f1fd` | `#0b63c5` |

線とラベル：通常 `stroke="#333"`／成功の戻り `stroke="#383" stroke-width="2"`・ラベル `fill="#383"`／取り消し・失敗 `stroke="#b33"`・ラベル `fill="#b33"`／つながりの補足（共用・参照）は破線 `stroke-dasharray="5,3"`／補足の文字 `fill="#555"`／注意の注記 `fill="#c05000"`。

全体像のフェーズの箱も同じ表から選ぶ：ロジック＝既存の処理・ロジック、共通化＝中核・共有部品、利用側＝利用側、仕上げ＝環境・補助。

## 部品

### 矢印の定義（ページで 1 回）
```html
<defs><marker id="a" markerWidth="8" markerHeight="8" refX="7" refY="4" orient="auto"><path d="M0,0 L8,4 L0,8z" fill="#333"/></marker></defs>
```
- 最初の SVG に 1 回だけ置き、後の図も `marker-end="url(#a)"` で使い回す。**最初の図を消すときは、`<defs>` を次の図に移す**（消すと全部の矢印が消える）。
- 別の定義を足すなら id を変える（`id="b"`）。同じ id を 2 回定義しない。

### 箱（見出し＋説明 2 行＋補足）
```html
<rect x="10" y="20" width="210" height="100" fill="#dff" stroke="#08a"/>
<text x="20" y="42" font-weight="bold">見出し</text>
<text x="20" y="62" font-size="12">説明 1</text><text x="20" y="78" font-size="12">説明 2</text>
<text x="20" y="102" font-size="12" fill="#555">補足（コミット数など）</text>
```

### 箱の中の小さい箱（部品の中身を見せる）
```html
<rect x="10" y="20" width="310" height="200" fill="#efe" stroke="#383"/><text x="20" y="40" font-weight="bold">外側の部品</text>
<rect x="20" y="50" width="290" height="32" fill="#fff" stroke="#888"/><text x="28" y="71" font-size="12">中の要素（白地）</text>
```

### 矢印とラベル
```html
<!-- 横：始点＝左の箱の右端、終点＝右の箱の左端。ラベルは線の少し上（y−6） -->
<line x1="220" y1="70" x2="280" y2="70" stroke="#333" marker-end="url(#a)"/><text x="226" y="64" font-size="11" fill="#555">ラベル</text>
<!-- 縦 -->
<line x1="385" y1="70" x2="385" y2="100" stroke="#333" marker-end="url(#a)"/><text x="392" y="90" font-size="12">条件</text>
<!-- 戻り（右→左）。成功は緑の太線、取り消しは赤 -->
<line x1="660" y1="100" x2="280" y2="100" stroke="#383" stroke-width="2" marker-end="url(#a)"/>
<!-- 破線（共用・参照） -->
<line x1="90" y1="265" x2="90" y2="174" stroke="#a3a" stroke-dasharray="5,3" marker-end="url(#a)"/>
<!-- 留まる（同じ箱へ戻る弧） -->
<path d="M800,150 C800,180 870,180 870,150" fill="none" stroke="#888" marker-end="url(#a)"/>
<!-- 1 か所から 3 つに分ける（破線の横棒＋縦の矢印） -->
<line x1="785" y1="185" x2="175" y2="185" stroke="#333" stroke-dasharray="4,3"/>
<line x1="175" y1="185" x2="175" y2="215" stroke="#333" marker-end="url(#a)"/><line x1="480" y1="185" x2="480" y2="215" stroke="#333" marker-end="url(#a)"/>
```

## 4 種の図の使い方
1. **全体像**：フェーズの箱を横に並べる。4 つ＝幅 210・間 30（x = 10, 250, 490, 730）、5 つ＝幅 175・間 15、3 つ＝幅 290・間 45。中身は「番号 名前（太字）」「主な部品 2 行」「n コミット（灰色）」。
2. **前／後**：上に「前」（問題の形を、問題の箇所の色で 1 つの箱に）、下に「後」（共有の部品 → interface ← 利用側 2 つ）。共用する資源は共有の部品の下に小さく。既存の利用側は「既存の処理」の色、新しい利用側は「利用側」の色。
3. **状態遷移**：左右に状態の箱（ふだんの状態＝既存の処理、特別な状態＝強調）、間に 3 本の矢印（上＝入る、緑＝成功で戻る、赤＝取り消しで戻る）、下に「失敗で留まる」の弧。状態が 3 つ以上なら、箱を三角形に置いて矢印を足す。状態の表（操作 → 結果）と必ずセットにする。
4. **分かれ道（フロー）**：入口（利用側）→ 判定（処理）→（右へ）当たらない＝今までどおり（補助）／（下へ）当たる → 下段に 3 つの場合（すぐ処理＝利用側、待ってから処理＝強調、代わりの処理＝問題の箇所の色）。手順の番号付き箇条書きと必ずセットにする。

## md 側の図
md には SVG を入れない。全体像と前／後は、同じ内容を `pre` の文字の図（`──▶`・`├─`・`└─`）にする。状態遷移とフローは、md では表と手順の箇条書きにする（HTML の図と同じ内容）。

## よくある崩れ（確かめる所）
- 説明の行が箱の右端からはみ出す → `svg-check.js` で検出。文言を短くするのがいちばん安全。
- 矢印のラベルが次の箱に食い込む → 検査にかからないので、ラベルの右端の x を目で確かめる。
- 縦に並べた箱の補足（`fill="#555"`）が下の箱に重なる → 箱の高さを、行数 × 18 ＋ 30 以上にする。
- 図を消したら矢印が全部消えた → `<defs>` を消した。次の図に移す。
